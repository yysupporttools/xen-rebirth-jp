# 管理者ページ

入口は `https://yysupporttools.github.io/xen-rebirth-jp/admin.html` です。ブックマークして利用してください。

一般向けの「便利機能」、ホームのギルド紹介、ページのフッター、サイト内検索には管理リンクを表示しません。`admin.html`、`reports.html`、`guild.html` は検索エンジン向けに `noindex,nofollow` を指定し、サイト内検索・人気記事・最近見た項目の対象から除外します。

既存の質問掲示板の管理者アカウントでログインすると、修正報告・投稿管理とギルド紹介の編集へ進めます。ログインメールの送信は既存アカウント限定です。メールに確認コードが届く場合はコードでもログインできます。管理権限のないアカウントから新規登録したり管理機能を利用したりすることはできません。

メールの戻り先には、Supabase Auth がすでに許可している board.html と固定の管理画面用マーカーを使います。掲示板の認証・記事読み込みを始める前に、メールの認証情報を同じサイトの admin.html に引き継ぎます。戻り先を利用者が指定する方式ではありません。管理権限は管理ページで改めて確認します。認証失敗時はメールサービスがマーカーを消すため、同じブラウザに残る15分以内のログイン操作記録がある場合に限り管理ページへ戻します。この記録にはメールアドレス・認証情報を保存しません。別ブラウザで期限切れのメールを開いた場合は、ブックマークした管理ページからログインし直してください。

画面は最初から閉じた状態で、Supabase Auth の `getUser` と `board_is_admin` による実際のログイン・管理権限確認後だけ開きます。保存の直前も同じ確認を行います。共有するログイン保存キーは既存の `xen-board-admin` です。

ログアウト、ログインの失効、非管理者判定、アカウント変更では、取得済みの投稿や編集中のフォーム・画像プレビューを消去します。再確認中は管理機能を隠し、同じ管理者の確認が完了した場合はギルドの未保存の文章・写真を保持します。古いアカウントの読み込みが後から完了しても表示しません。

GitHub Pages は静的公開のため、管理ページのURL自体を非公開ファイルにする方式ではありません。一般の訪問者には入口を表示せず、URLを直接開いてもログイン案内だけを表示します。管理情報の取得・更新は既存の Supabase Edge Function のサーバー側管理者確認と、非公開スキーマ・RLS・クライアントへの権限なしの構成で保護します。管理者判定やサーバー権限は変更していません。

検証: `outputs/admin-entry-20261009/test-admin-lifecycle.cjs` は実際のフロントエンド処理を制御された認証・通信・DOMで実行し、匿名/管理者/非管理者/失効/権限エラー/一時的通信エラー/ログアウト競合/アカウント変更、遅延応答、ギルド下書き・写真の保持と消去、既存アカウント限定ログインを確認します。実アカウントへのログインメールや公開データの更新は検証で行いません。
