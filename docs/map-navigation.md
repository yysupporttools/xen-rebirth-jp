# マップナビ

`map.html` は保存済みのゲーム内拡大マップ、NPC位置、会話情報、モンスター図鑑を利用して現在地から目的地を案内します。便利機能の「マップナビ」から開けます。

## 利用方法

- 現在マップと行先を選びます。NPC・モンスター名を検索して目的地を選ぶこともできます。
- Lv、Library Card、Garciaの前提クエスト、サーバー時間が土日かどうかを入力・確認して経路を絞れます。
- 画像と対応するNPC座標を表示します。矢印は目的地の方向であり、壁を避けた歩行経路を算出するものではありません。
- 現在位置や不足した目印は地図をクリックして補えます。この位置指定は自端末に保存し、他のプレイヤーの登録情報を変更しません。
- 画像が未登録のマップは、全体を切り抜いた拡大マップを貼り付けるか選択して保存できます。登録済み画像は「画像を更新」から、貼り付けまたはファイル選択で差し替えられます。変更前の画像を保持し、自動収集では手動画像を上書きしません。
- 翻訳・NPC検索で画面共有と自動解析を有効にし、拡大マップを開くと画像・NPC位置を蓄積します。NPC会話を閉じてマップを表示してください。別タブの現在地表示にも連携します。

## データと案内条件

- 登録済みワールドマップの明示接続を利用し、提供された町間転送50件・NPC移動7件・Mall Streetの入口1件を追加しています。転送は方向ごとに登録し、帰りのサービスを推測して追加しません。
- Oasis・Albatross Cityにはトランスポーターからの出発経路を設定していません。
- LogatherのLibrary/B2/B4/roomはLv70以上・Library Card、GarciaのShipdockはLv100以上・前提クエスト完了、Event GuideのAisenはサーバー時間の土日のみです。サーバーの時差を推測しません。
- Pirates Ship dock・Brynhilld Culvertは拡大マップなしとして、出発NPCや入口・手順を表示します。
- Brynhilldの転送サービスの出発区画は、保存済み会話で確認できたArcarinas SquareとSummer Hill Streetに限って関連付けています。到着区画・到着座標は未確認です。
- Town of Deceasedは登録済みのVillage of the Deadとの同一性が未確認のため、別の行先として保持しています。
- 座標は元の地図画像IDに結び付け、未登録の位置や別画像の座標を推測しません。モンスターは出現マップまでの案内です。

## 維持と確認

`map-transports.js` は提供された転送・入口と条件、`map-navigation.js` は経路・画像と座標の照合、`map-navigation-data.js` は公開データの読み込みと未登録画像の追加、`map-location.js` は現在地共有、`map-navigator.js` は画面操作です。

`test-map-navigation.cjs` と `test-map-location.cjs`、作業フォルダーのデータ・画面操作テストで検証しています。既存の保存処理と公開データを利用し、画像更新専用の保存処理と履歴領域を承認のうえ追加しています。詳細は map-image-updates.md を参照してください。

四季イベントの日本語要約は用語集の `four-seasons-event` に登録済みです。参加方法・季節マップ・Sign・交換概要・公式出典を記載しています。

英語のマップ名はゲーム内表記を正とし、確認済みの旧日本語名を併記・検索に使います。旧表記や元の保存IDを保持したまま同じ場所へ統一します。NPCの緑の目印は初期状態OFFで、チェックボックスから表示できます。
