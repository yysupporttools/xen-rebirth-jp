# 地域・マップ別の新規モンスター登録
既存図鑑と登録済みマップ・正規名称リストを結合した monster-map-catalog.json を利用。既存地域の分類を保持し、追加エリアは検索用の周辺グループとして整理。モンスターの存在・Lv・ドロップは自動推測しない。
登録は site-feedback create_monster から service_role 限定 RPC site_feedback_create_monster を呼ぶ。既存の保存回数制限・投稿履歴・公開投影を再利用し、catalog_entry に名前と地域を保存する。名前とマップ単位のロックで再送を重複登録しない。
Lv 空欄は未確認。情報だけ保存した後も詳細から画像を追加できる。「登録して画像を追加」は保存後に既存の貼り付けダイアログへ進む。画像保存の失敗でモンスター登録を重複させない。
RPCはanon/authenticatedに直接公開しない。Edgeは既存のAPIキー・Originチェックと入力検証を継続。追加したIDも既存の画像追加・詳細編集で解決する。
検証: scripts/test-monster-create.cjs、ブラウザの地域/マップ選択・新規登録・再読込・画像追加への遷移・重複防止・スマートフォン表示。SQLの登録・再送・公開投影テストはトランザクションをロールバック。
