# モンスターのメイン画像と追加画像の削除

新しい追加画像を一覧と詳細のメイン画像に優先表示します。URLを検証し、表示できないときは古い追加画像、公式画像の順に切り替えます。全候補が失敗した場合は未取得表示にします。拡大表示の画像URLも切替先へ更新します。

追加画像の削除は site-feedback の image_permissions / delete_image を使い、投稿者本人またはサーバーで確認した管理者だけが実行できます。新しい画像の投稿時には、ブラウザーUUIDのSHA-256を非公開 submissions.image_owner_hash に保存します。この値を公開の monster_updates や権限確認・管理画面の応答に含めません。

過去の匿名画像には投稿者の識別情報が保存されていません。所有権を推測せず、管理者のみ削除できます。管理者のセッションは掲示板と同じ xen-board-admin を使い、Edgeでは Auth user と board_is_admin を毎回確認します。公開ページに管理メニューやログインリンクを追加しません。

削除は指定した image 投稿の公開行だけを除去し、非公開の元投稿を rejected として保持します。別の画像やLv・ドロップなどの情報を変更しません。元の画像ファイルと非公開の確認画像は保持し、誤操作から管理者が回復できる状態にします。削除後の再読込みは xen-monster-updated を使い、次の残った画像に切り替えます。

保存・削除RPCは SECURITY INVOKER と空 search_path、service_role の EXECUTE のみです。公開のanon/authenticatedの書込み権限は追加していません。実際のEdgeコードを使う権限・ID検証テスト、表示・削除の画面操作テスト、実DBのROLLBACK付き仮データ検証に合格しました。
