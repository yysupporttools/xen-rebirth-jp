# モンスター画像の追加上限

ゲーム内画像を連続して登録できるよう、画像だけの追加枠を修正報告とは別にしました。

- 画像の追加：10分間に60枚、日本時間の1日に500枚。
- Lv・ドロップ・DEFなどの情報追記、記事の修正報告：従来どおり10分間に5件、1日に30件。
- ブラウザ識別子と接続元それぞれに上限を設けます。識別子・接続元はサーバーでハッシュ化し、画像用の別の値を使います。
- 接続元の画像用キーは日付で変えません。10分間の枠を日付が変わっても保ち、DBが日本時間0時に1日の枠だけをリセットします。
- 以前の報告・投稿・カウンターは消しません。画像用の新しい枠に切り替えるため、以前の報告上限で画像追加が止まることはありません。

専用の `site_feedback_submit_image` はサーバーだけが実行できます。画像追加の2つの上限判定、カウンター更新、確認用受付レコードの作成を同じトランザクションで行います。画像の公開処理、画像形式・容量検証、管理者の非表示・削除機能は変更しません。

`docs/monster-image-rate.sql` を適用し、`site-feedback` のEdge Functionを更新します。既存の `site-feedback.sql` は再適用しません。
