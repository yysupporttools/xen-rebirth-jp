# 地名の統一

翻訳・NPC検索ページの地名は、登録済みワールドルートと確認済みの別表記を参照して表示・検索・保存します。

- Arcarinas Square の8通りの表記、Brynhild / Brynnhild、Jotunnheim、Titans / Titarius Plains などを同じ登録済み地名として扱います。
- 新しい読み取り結果、手動登録、NPC画像、マップ画像の登録前にも同じ辞書で地名を確認します。既存のマップ・NPC画像を更新するときは、元の登録先を引き継ぎます。
- 自動読み取りで同じNPC・地名・クエスト・英語本文の会話を再保存する場合は、既存の会話IDを使います。本文の違う会話は削除・統合しません。手動の会話保存も統一した地名を使いますが、過去の会話行を一括で統合する処理は行いません。
- 大文字・小文字、空白、句読点、全角表記を正規化します。未登録の表記は、地形・方向が一致し、1文字の違いで一致する候補が1つだけの場合に限り補正します。
- B1F / B2F、入口 / 出口、東西南北を混同しません。階層の表記は明示した別名以外では推測しません。候補が曖昧な地名や未知の地名はそのまま残します。
- 検索は元の表記でも使えます。「すべてのマップ」の選択肢は統一した地名を1回ずつ表示します。
- 同じ地名のマップ画像が複数ある場合は、ひとつの地名から保存済み画像を切り替えられます。画像とNPC座標の関連は元のIDのまま保持します。

## データの保持

この変更はサイト側の表示・登録処理に適用しています。データベースの構造、既存の地名文字列、会話ID、画像URL、NPC座標、写真、会話の識別情報を変更・削除していません。

確認時点の31通りのNPC会話用地名は、統一後の表示では20通りです。240件の会話、102件のNPC写真プロフィール、17件のマップ画像登録、303件のNPC座標、808件の観測記録を保持しています。Brunen Basin / Brunnen Basin の2画像も保持しています。

既存のArcarinas Square拡大画像を標準表示にし、元の町名で保存したマップ・NPC写真・座標・会話IDは別画像の登録先も含めて保持します。50件の確認済み片方向転送とLv条件は維持し、Summer Hill Streetは別地区の同じ行先の出発サービスだけを参照します。到着座標・未登録の入口座標は推測していません。データベース上の物理的な行統合・削除・地名変更は行いません。

## 旧日本語名の補助表示

管理者が提示した旧日本語版の地図から、文字と経路・固有名詞の対応を確認できた100地点の旧日本語名を登録しました。英語のゲーム内マップ名を主表示にし、旧日本語名を補助表示・検索用に使います。現在の公式日本語名や英語名の直訳ではありません。対応や文字が不確かな地点は登録せず、NPC名も翻訳していません。

map-japanese-names.jsonのnamesが確認済み辞書の原本です。build-map-registry.cjsは重複する日本語名・未登録の英語名を拒否し、旧日本語名の検索別名とmap-japanese-names.jsを生成します。入力・保存キー・既存IDは英語の登録先を維持します。

## 辞書の更新

`scripts/build-map-registry.cjs` は `dist/assets/world-routes.js` の地名と別名を読み、確認済みの別表記を加えて `dist/assets/map-registry-data.json` と `dist/assets/map-registry.js` を生成します。

新しい別表記は `verified` に追加し、生成後に `scripts/test-map-registry.cjs` で確認してください。類似する別マップの名前は別名として追加しないでください。
