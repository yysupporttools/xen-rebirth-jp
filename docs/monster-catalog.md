# Monster catalog sources

Reviewed: 2026-10-05 (Japan time).

The static catalog has 25 regions and 879 map-specific occurrences. Level values are recorded for 812 occurrences; 786 include game screenshots. Missing values stay null. Image URLs refer to the official community Lexicon attachments.

Monster images and names remain the property of their respective rights holders. Original articles are credited in each detail view. Descriptions are summarized; numeric facts retain their sources.

DEF values are map references with the original `2+` notation. They are not universal per-monster requirements. Individual values are used only where the guide explicitly names the monster. Normal monsters and Hard Hitters remain distinct. Conflicting source values remain visible. The attached Defense Calculator (Beta).xlsx, Where Can I AoE!E2:H144, contributes map references; the original workbook is not published.

The article report API stores pending submissions and attachments privately. Moderation uses the existing question board administrator role. Approved monster additions are published separately. Initial unknown level/image fields may be filled by approved posts, with an explicit post label.
