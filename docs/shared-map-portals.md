# サイト共通の入口・出口

map_portalsは公開読み取り、管理者のみ追加・修正・削除。既存board_is_admin()で判定し、利用者メタデータは使わない。入口・出口には画像識別子を保存し、画像更新後の別画像には表示しない。位置は画像全体に対する0〜1000の正規化座標。印の移動先は表示用で、未確認の逆方向や地図接続を自動追加しない。更新・削除はupdated_atを条件にして同時編集の上書きを避ける。

管理者ページからマップナビを開き、「入口・出口を追加」→種類・表示名・移動先→地図をクリック→「サイト共通で保存」。既存の印は「編集・移動」または「削除」。一般利用者には編集ボタンを隠し、データベースでも変更を拒否する。

SQLロール検証はトランザクションで匿名・非管理者の拒否と管理者の作成・更新・削除を確認し、ロールバックした。画面の模擬操作でも画像ごとの分離、拡大後の座標、保存失敗時の再操作を確認。

採用したLevel 1のみAI補完画像を表示する。Level 2の生成画像は不採用で、既存の部分図を保持する。生成画像はbuiltin image_genを使用。採用元画像はタスク出力sleepless-grave-level-one-clean-v1.png。画像は未撮影部分の推定を含むため、公式の測量図ではない。


マップ名の手動修正はmap_name_correctionsに保存。旧名・既知の別名を新表記へ解決し、画像IDとNPC座標は変更しない。旧表記Shalo Forestは、画像内のShaio Forestへ修正。管理者はマップナビの「マップ名を修正」から保存できる。一般利用者には編集操作を表示せず、DBのRLSでも拒否する。マップナビと翻訳・NPC検索で修正情報を読み込む。別の既存マップとの統合はこの編集では許可しない。
