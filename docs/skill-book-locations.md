Official updatedAt: 2024-05-10T07:21:46-05:00. Checked: 2026-10-06.

Published at `dist/systems.html#skill-books`, with a home guide card and update entry.
The static details tables contain 26 target-level groups (31–156, step 5) and 185 non-empty map/route rows.
Lv156 has no source locations; it is deliberately marked as unlisted. Empty source table rows are omitted.
The level is the skill book target level, not skill level or monster level. No class, named skill, named drop monster, or drop rate is inferred.
Original map spelling is preserved. Source route text is translated to Japanese.
Lv86 Empion Forest has two different source routes, both retained. Lv66 Lombard Plains has an inconsistent source link to Taisen Plains; source map text is used and map hyperlinks are omitted.
The source route marker Templar+ is preserved without interpreting it as an entry restriction.
Source comments are not merged into the main table.

The complete table is readable without JavaScript. JavaScript adds target-level and location/NPC text filters without fetching external data.
Site search indexes the static section during the existing Pages build.
