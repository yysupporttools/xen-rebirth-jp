# デフォルメ・モンスターデコレーション

ユーザー提供の7枚のゲーム内画像を参考に、それぞれ独立した背景透過のデフォルメ画像を生成。装飾用WebPは384px、約20〜50KB/枚。assets/monsters/chibiに保存。

random-monsters.jsはページ読み込み時に7種類をシャッフルし、タイトル付近へ1体を表示。ホームではヒーローと6枚の案内カードに、1巡で重複しない7種類を表示。閲覧中に画像を切り替えるタイマーはなし。装飾画像はalt空・aria-hidden・pointer-events:none。画像が取得できなければその画像を除去。埋め込みiframe内には表示せず、独立したツールページでは表示。

24ページのheadにCSSとdeferスクリプトを追加。既存のBGM横のマスコットは維持。ホームの旧ヒーロー/カード装飾は新しい装飾がある場合のみ非表示。

ゲームシステムページは既存の用語集・クエストDB・転職ページを元に12テーマへ拡充。#pets / #mounts / #party / #guild / #dungeonsの既存リンクを維持。詳細素材などはdetailsへ収納。出典へのリンクを保持し、登録済み攻略情報へのリンクを追加。クエストIDと用語slugの存在をDB照合済み。
