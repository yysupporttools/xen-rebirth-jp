# Xen Rebirth マップ連携 β

提供された v0.14.2β のマップ接続・出口座標・クリック透過表示をサイト連携用に移植しました。
元の翻訳ツールとゲームファイルは変更しません。現在地は「エリア名」で、キャラクターの座標追跡や自動移動ではありません。

## 起動

1. ZIPを展開し `START_MAP.bat` をダブルクリックします。
2. 元の `XenRebirthTranslator_v0.14.2beta_EirCandyvaultFix_Portable` フォルダーを選びます（runtime / tesseract を含むフォルダー）。既存のPythonとOCRを利用します。
3. ゲームをウィンドウまたはボーダーレス表示にし、拡大マップを開きます。
4. 「マップ範囲を指定」でタイトルを含む正方形の枠全体をドラッグ。「案内を開始」を押します。
5. Chrome / Edgeで https://yysupporttools.github.io/xen-rebirth-jp/capture.html#map-database を開きます。
6. ツールの「接続コードをコピー」からサイトへ貼り付け、「常駐ツールに接続」。ブラウザーにローカル接続の許可が出たら許可します。
7. サイトで行先を指定します。ゲーム画面の拡大マップに次の出口の矢印が表示されます。

拡大マップ上の行先選択からも指定できます。テンキー0で縮小／復元できます。
サイトを閉じても常駐ツールの案内は続きます。終了はツールの「停止」またはウィンドウを閉じます。
元のツールのマップ案内はOFFにして、矢印が二重にならないようにしてください。

## 収集と更新

- OCRはPC内で実行し、外部AIやAPI料金は発生しません。
- 同じタイトルを連続して認識すると、新しいエリアを行先一覧へ追加します。
- 登録済みエリア名の出口ラベルを複数回、近い位置で読めた場合、その向きの接続と出口位置を追加します。逆向き接続は推測しません。
- 新エリアを登録した後、隣接するエリアも再度開くと接続を収集できます。未確認の出口や障害物を避ける移動経路は推測しません。
- 確認済み出口座標を優先します。未確認なら矢印を出さず、出口の読み取り待ちを表示します。
- 徒歩を標準にしています。NPC移動を含める場合はサイトのチェックをONにしてください。入場Lv・クエスト条件はゲームで確認してください。
- 収集した画像、NPC・モンスター名、接続情報は `%LOCALAPPDATA%\XenMapCompanion` に保存します。サイトは接続中にそのPCの記録を表示します。全利用者への自動公開は行いません。
- エリアの読み違いはツールの「現在地を修正」。収集した接続情報はサイトから削除・JSON書き出しできます。
- 削除した名前は再収集を抑止します。再登録したい場合は、そのマップを表示してツールの「現在地を修正」で同じ名前を登録してください。

## 制限とトラブル時

- β版です。実ゲームの解像度・表示倍率・テーマでOCR精度が変わります。画面位置が変わった場合は範囲を指定し直してください。
- 最小化したゲーム、排他的フルスクリーン、黒画面では認識できません。
- 起動中のみ127.0.0.1:18765で連携を受け付けます。接続コードは起動ごとに変わります。攻略サイト以外のOriginとコードなしの要求は拒否します。
- WindowsのポリシーでPowerShell起動が禁止されている場合、ポリシーを変更せずに管理者へ確認してください。Pythonから起動する場合は XEN_PORTABLE_ROOT を元ツールのフォルダーに設定して start.py を実行します。
- 保存先を変える開発用設定：XEN_MAP_DATA。停止後も収集記録は残ります。
